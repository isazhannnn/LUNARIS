# Visual assets

Created and selected for LUNARIS by Parsec Studio. Fictional environment and cover illustrations were generated with OpenAI image-generation tools. The four README gameplay images are actual captures from the running game. Their raster encodings were compressed for documentation, then placed inside labelled SVG documents; gameplay content was not generatively redrawn.

Each submitted SVG visibly identifies generated content and records original and embedded raster checksums. `ASSET_MANIFEST.json` lists all such assets. The SVGs are self-contained and can be opened in a browser. The game also draws a persistent visible label over generated environments so it remains present while the camera moves.

The Signal L logo in `assets/brand/` is a geometric SVG mark. The cover uses Kazakhstan and United States national flags; no NASA agency logo, NASA flag or official mission identifier is used in generated artwork. No real person appears in these submission visuals.
